# Roadmap: Azure and Cloud

## Objective

Understand cloud foundations and implement selected local data and ML capabilities using Azure managed services.

## Prerequisites

- relational databases
- pipelines
- APIs and Docker
- MLOps foundations
- basic networking and command line concepts

## Practical milestones

- create a controlled Azure resource structure
- upload and retrieve data securely
- connect to a managed database
- run a managed pipeline
- submit a model training job
- register a model
- deploy a containerized workload
- use Key Vault for secrets
- configure monitoring and cost alerts
- remove resources safely when no longer needed

## Completion criteria

- can map local system concepts to cloud services
- can manage identity and secrets responsibly
- can deploy and monitor a small data and ML system
- can reason about cost, security, and service selection
- can explain the architecture without relying on product-name memorization
